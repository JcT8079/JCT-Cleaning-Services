JCT Cleaning Services - New Homepage

Files:
- index.html
- styles.css
- assets/ (images cropped from the supplied homepage design)

How to preview:
Open index.html in a web browser.

How to publish:
Upload index.html, styles.css, and the assets folder to the root folder of your website host. If your current homepage file is named index.html, back it up before replacing it.

Important:
This package is a functional responsive recreation of the supplied design. The images are cropped from the design mockup, so replacing them later with the original full-resolution logo and photographs will improve image quality.
